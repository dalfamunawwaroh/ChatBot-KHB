1. Data yang Dikumpulkan

  1. Akun: nama, email, nomor WhatsApp (opsional), organisasi.
  2. Interaksi: riwayat pertanyaan chatbot untuk peningkatan jawaban.
  3. Teknis: tipe perangkat & log error anonim untuk stabilitas.

2. Penggunaan Data

  • Menyediakan & memperbaiki jawaban edukasi halal.
  • Notifikasi penting (pembaruan dokumen, keamanan akun).
  • Analitik agregat performa chatbot — tanpa identitas personal.

3. Penyimpanan & Keamanan

Akses data dibatasi untuk admin KHB. Kredensial disimpan terenkripsi. Riwayat chat demo pada prototipe ini dapat dihapus berkala tanpa pemberitahuan.

4. Hak Anda

Minta salinan, koreksi, atau penghapusan data via kanal resmi KHB di halalbandung.com. Permintaan wajar diproses maksimal 14 hari kerja.

ⓘ Prototipe demo: hindari memasukkan data sensitif (NIK, password lain, rahasia dagang) ke kolom chat.
